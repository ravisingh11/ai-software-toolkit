# AI Software Toolkit v2.2.1

**Draft for maintainer review — not published.**

This patch renames the composite GitHub Action to **AI Software Toolkit Proof
Attestation** for Marketplace submission. The CLI version is 2.2.1. The action's
repository path, required inputs, and execution remain unchanged. The independent
Spec Kit preset keeps version 1.0.0. Publication documentation finalized after
v2.2.0 is included; no additional runtime or policy behavior change is intended.

## Compatibility and adoption

All checks remain optional to adopt and enforce. Existing advisory findings stay
visible. GitHub required merge checks remain separate from toolkit policy.
Advanced lifecycle and polyglot workflows remain manual. This release does not
enable a provider, deploy a consumer application, or import newer policy into
historical evidence. See the [v2.2.0 notes](v2.2.0.md) for the unchanged feature set.

## Draft assets and verification

Review the CLI archive, source archive, Spec Kit preset ZIP, their individual
SHA-256 files, these release notes, Marketplace metadata, release manifest, and
SHA256SUMS together. The manifest records the exact merged source commit, source
tree, required hosted CI, archive inventory verification, file sizes, and hashes.
SHA256SUMS covers every attached file except itself; the manifest lists content
assets and individual checksum files without a circular self-hash.

No extra local tests are run for this preparation. Required hosted CI validates
the final prep PR head; the candidate manifest records whether that head's tree
matches the merged revision used for packaging. Local packaging and archive/hash
inspection are separate from tests. Built archives are not claimed to have native
build-provenance attestations. Published-byte verification attestations can only
be produced after a later authorized publication.
