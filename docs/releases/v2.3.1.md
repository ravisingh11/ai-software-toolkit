# AI Software Toolkit v2.3.1

**Draft for maintainer review — not published.**

This patch makes the existing starter installation and skill procedures easier
to find and use. It does not change control selection or evaluation semantics.

## Changes

- README and quickstart describe the existing Proof-plus-seven-skills starter
  default, with explicit Codex or Claude project destinations and a Proof-only
  alternative. Existing consumers retain their selected installation.
- [Workspace and skill onboarding](../skill-onboarding.md) explains saved
  project paths, discovery, explicit invocation and selecting the intended copy.
  [AGENTS.md](../../AGENTS.md#choose-a-skill-for-the-task) routes maintainer tasks
  to the canonical skills without installing the entire catalog.
- [Real-client verification](../skill-verification.md) separates installation,
  discovery, invocation, task output and outcome verification. Five actual
  Codex CLI 0.163.0 demonstrations have captured, hash-bound patches and hosted
  behavioral checks, including negative controls. These are isolated fixture
  results, not current application QA, native provenance or Claude verification.
- Validator tests no longer depend on blank production verification ledgers.
  Source-history checkout runs only when the maintainer skill validator exists;
  ordinary consumers keep shallow checkouts. Shipped, installed and embedded
  demo workflow copies remain synchronized.
- The changelog and release index correctly identify v2.3.0 as published;
  historical preparation notes and release assets remain intact.

## Compatibility and adoption

The CLI reports 2.3.1. All 33 checks remain discoverable, checks remain optional,
Core stays advisory, and lifecycle/polyglot execution stays manual. Existing
schema versions, runtime paths, provider/policy definitions, scoring, skill
procedures, and installation-set behavior remain unchanged. README installation
examples continue to reference the published v2.3.0 release during preparation.

The Action remains **AI Software Toolkit Proof Attestation** with unchanged
inputs and execution. Marketplace metadata accompanies the assets; its presence
does not establish Marketplace acceptance or publication.

The CLI archive excludes the optional Spec Kit preset and packager. The full
source archive retains both for explicit adoption; the preset's independent
version stays 1.0.0. No historical release is replaced.
