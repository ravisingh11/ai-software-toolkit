# AI Software Toolkit v2.2.0

**Release v2.2.0 · 2026-10-21 (America/New_York)**

Reviewed source: `7b6638e001a27ebcda33202355926435c62234bd`.

This minor release adds optional independent security workflows and makes
scorecards easier to adopt at the project's current stage.

## Changes since v2.1.1

- Group checks into Selected checks, Tools available to adopt, and Checks
  relevant later. Score only the stage's selected checks. Link all 33 built-in
  checks from the overview near the top of the page.
- Separate Advisory / Enforced policy from provider configuration, activation,
  and execution. Explain missing or ambiguous evidence as Unable to verify;
  retain real failures, hide zero result counts, and improve mobile presentation.
- Select advisory Dependabot verification for the toolkit repository and make
  missing settings proof explicit. Consumers choose their own configuration.
- Add independently adoptable Trivy dependency and IaC scans, manual image scans
  with SBOM output, and exact published release-asset verification attestations.
  Include toolkit Python requirements files in dependency scans. Direct-input
  scans do not resolve unlisted transitive dependencies.
- Improve onboarding with a published-release quickstart, current scorecard
  examples, optional adoption guidance, and clear limits on installed skill use.

## Compatibility and adoption

No breaking change to the documented Proof runtime paths or existing policy
and evidence schemas is intended. Scorecard output adds stage and selection
metadata; existing consumers should preserve unknown fields. The CLI version
is 2.2.0. The Spec Kit preset keeps its independent version 1.0.0.

All checks remain optional to adopt and enforce. Advisory findings remain
visible; configured Enforced checks require passing evidence for the toolkit
decision. GitHub required merge checks are separate. Polyglot examples and
advanced lifecycle execution remain manual. No provider account, AI execution,
production deployment, or additional enforcement is enabled by this release.
Preview consumer updates and review retained local configuration before applying.
