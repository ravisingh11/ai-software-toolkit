# Release notes

Use a published release for a stable toolkit revision. Changes on `main` after
that release are listed under [Unreleased](../../CHANGELOG.md#unreleased).
Release notes describe the evidence and limits for that particular release;
they do not establish the status of a newer revision or a consumer application.

| Release | Scope |
| --- | --- |
| [v2.1.1](v2.1.1.md) | Published patch release; see its GitHub release for final assets and publication evidence |
| [v2.1.0](v2.1.0.md) | Shared CLI distribution, optional providers and lifecycle checks, scorecards, and Claude Code onboarding |
| [v1.0.0](v1.0.0.md) | Initial stable Proof runtime and public contract |

See [all published GitHub releases](https://github.com/ravisingh11/ai-software-toolkit/releases)
for tags and assets, and the [changelog](../../CHANGELOG.md) for the complete
version history. Earlier changes do not all have separate release-note pages.

The missing v2.1.0 GitHub Release record was restored on 2026-10-21 against
the unchanged tag. Rebuilt assets are identified in its manifest; original
asset-byte equivalence is not claimed. See the [restoration note](v2.1.0.md#release-record-restoration--2026-10-21).
